### 描述
FileToImage 是一个文件与图片互转工具，支持加密与压缩。
提供图形界面与命令行两种模式。

### 安装依赖
在项目目录下运行：
```
pip install -r requirements.txt
```

### 使用
- **图形界面**：直接运行 `main.py` 或 `file2img.py`，交互式选择文件与密钥。
- **命令行**：`python main.py -e -f 文件路径 -p 密码`（编码）或 `-d`（解码），详见 `-h`。
- 密钥可选，建议使用高熵字符串。

### 机制
转换时会保留原文件名及完整数据。数据经随机盐 + 流密码加密，SHA-256 完整性校验，支持 raw / zlib / bz2 / lzma 压缩。
